Cara Pasang di HP (Vercel)

📌 Langkah Deploy di Vercel:

  1. Upload file index.html ke repository GitHub.
  2. Buka Vercel.com & login pakai akun GitHub.
  3. Pilih Import Repository lalu klik Deploy.

📱 Android (Chrome):

Buka link Vercel kamu → Tekan titik tiga ⋮ → Pilih "Add to Home screen" atau klik tombol hijau "Instal App" di atas.

🍎 iPhone (Safari):

Buka link Vercel kamu di Safari → Tekan tombol Share (Kotak Panah Atas) → Pilih "Add to Home Screen".
